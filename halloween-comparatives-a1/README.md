# Halloween Comparatives Quest

An interactive A1 English lesson with 13 sequenced challenges. The Halloween scene is the navigation map, with vocabulary flip cards and picture-based practice for comparatives and the present continuous.

## Files

- `index.html` — semantic lesson structure
- `style.css` — responsive Halloween visual system
- `script.js` — routing, feedback, progress, speech and activities
- `assets/` — user-supplied lesson artwork

The site is buildless and ready for static hosting or GitHub Pages. No external libraries are required.
