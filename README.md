# Was / Were — A1 interactive lesson

A responsive, framework-free lesson for practising **was / were** through guided discovery, controlled practice and personal speaking.

## Publish with GitHub Pages

1. Put `index.html`, `style.css`, and `script.js` in the same repository folder.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the branch and folder, then save.

No build step or external dependency is required.
